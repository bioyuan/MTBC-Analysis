# Characteristics of the pathogen spectrum in *Mycobacterium tuberculosis* complex-positive patients with lower respiratory tract infections: A nationwide observational study based on tNGS

This repository contains the analysis and figure-generation code, together with the aggregate data used to visualize the pathogen spectrum in the study.

## Data availability

The individual-level data used for logistic regression are confidential and are not publicly available in this repository. Requests for access to the original data should be directed to the corresponding author. Aggregate data for the figures are available in `01_data/`.

## Repository structure

- `01_data/`: aggregate counts and odds ratio estimates used for the figures.
- `02_code/01_logistic_regression.py`: crude and adjusted logistic regression analyses.
- `02_code/02_draw_figures.py`: code for Figures 1–4.
- `03_tests/01_test_models.py`: tests for the regression code using synthetic data.
- `04_generated_figures/`: figures generated by the plotting script.

## Requirements and usage

Python 3.12 is recommended. Install the required packages and run the scripts from the repository root:

```sh
python -m venv .venv
python -m pip install -r requirements.txt
python 03_tests/01_test_models.py
python 02_code/02_draw_figures.py
```

The figure script writes four PNG files (600 dpi) and four vector PDFs to `04_generated_figures/`. It uses Times New Roman when installed.

- Figure 1 connects each pathogen's ranks in the MTBC-negative and MTBC-positive populations and shows the prevalence ratios in MTBC-positive rank order. Asterisks indicate nominal two-sided chi-squared test thresholds of p < 0.05, 0.01, 0.001, and 0.0001, respectively.
- Figure 2 shows pathogen counts, crude odds ratios, and adjusted odds ratios with 95% confidence intervals.
- Figures 3 and 4 show odds ratios and 95% confidence intervals for sex and age strata and for regional strata, respectively. For these plots, estimates with five or fewer pathogen-positive records in the MTBC-positive group are omitted using the aggregate count tables.

## Logistic regression input

The regression script accepts a CSV file with one row per patient and the following columns:

| Column | Description |
|---|---|
| `mtbc` | MTBC status: negative = 0; positive = 1 |
| `age` | Age in years |
| `sex` | Sex category |
| `province` | Province-level administrative division. Use the standard full Chinese name or the English name listed below. |
| Pathogen columns | One column per pathogen: negative = 0; positive = 1 |

The script derives `region` from `province`. If the input already contains a `region` column, the derived values take precedence. Records with missing province labels are excluded from regional strata. Unrecognized province labels raise an input error.

| Region | Province-level administrative divisions |
|---|---|
| North | Beijing, Gansu, Hebei, Heilongjiang, Inner Mongolia, Jilin, Liaoning, Ningxia, Qinghai, Shaanxi, Shanxi, Tianjin, Xinjiang |
| East | Anhui, Fujian, Jiangsu, Jiangxi, Shandong, Shanghai, Zhejiang |
| Central-Southern | Guangdong, Guangxi, Hainan, Henan, Hubei, Hunan |
| Southwest | Chongqing, Guizhou, Sichuan, Tibet, Yunnan |

Example command:

```sh
python 02_code/01_logistic_regression.py --input private_data/input.csv --pathogens PJ,CRY,CAN --output private_data/model_results.csv
```

## Statistical analysis

Crude odds ratios (ORs) are estimated with MTBC status as the sole predictor. Overall adjusted models include age, sex, and province. Sex-stratified models adjust for age and province; age-stratified models adjust for sex and province; and region-stratified models adjust for age and sex.

Age groups are 0–14, 15–44, 45–64, and ≥65 years. For stratified models, strata with five or fewer pathogen-positive cases among complete records are excluded. Records with missing model variables are excluded from the corresponding model. The output includes ORs, 95% Wald confidence intervals, and two-sided p-values.

## Aggregate data

| File | Description |
|---|---|
| `01_overall_counts.csv` | Overall pathogen counts by MTBC status |
| `02_crude_or.csv` | Crude OR estimates |
| `03_adjusted_or.csv` | Overall adjusted OR estimates |
| `04_age_or.csv` | Age-stratified OR estimates |
| `05_sex_or.csv` | Sex-stratified OR estimates |
| `06_region_or.csv` | Region-stratified OR estimates |
| `07_age_counts.csv` | Age-stratified pathogen counts |
| `08_region_counts.csv` | Region-stratified pathogen counts |
| `09_sex_counts.csv` | Sex-stratified pathogen counts |

In the count tables, `mtbc_negative_positive` and `mtbc_positive_positive` denote pathogen-positive counts in the MTBC-negative and MTBC-positive groups, respectively. The `covariates_used` fields in the supplied stratified estimate tables record age, province, and sex for the age table, and include date for the sex and region tables; these recorded specifications differ from the stratified model settings described above.
